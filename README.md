# 📌 Featured Projects

### 🔧 Manufacturing Failure Diagnosis & RCA using GraphRAG
Hybrid enterprise intelligence system combining **Vector RAG, Knowledge Graphs, operational data, engineering rules, and evidence retrieval** for manufacturing root-cause analysis.

### 🤖 Agentic Warranty Intelligence
LangGraph-based workflow for **warranty claim investigation, fault-code interpretation, historical failure analysis, root-cause hypothesis generation, human review, and preventive maintenance intelligence**.

### ⚙️ Industrial Machine Anomaly Detection
Machine Learning and Deep Learning solution comparing **Isolation Forest and Deep Autoencoders** for industrial anomaly detection and predictive maintenance.

### 🔋 EV Battery Intelligence
Machine Learning and Deep Learning models for **State of Charge (SoC), State of Health (SoH), and Remaining Useful Life (RUL)** with MLflow experiment tracking.

### 📊 Retail Sales Data Engineering Pipeline
End-to-end data engineering solution using **Python, PostgreSQL, Apache Airflow, dbt, Docker, and GitHub Actions**.

### 🛡️ Vendor Risk Intelligence Platform
AI-assisted supplier compliance and risk assessment system combining **document retrieval, automated risk scoring, evidence analysis, and human-in-the-loop decision support**.
